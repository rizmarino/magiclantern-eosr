doom
====

Doom (doomgeneric engine) for the EOS R. Copy DOOM1.WAD (shareware) or another
IWAD into ML/DOOM on the card, then Games > Doom > SET.

Controls: joystick move/turn, SET or AF-ON fire, PLAY or M-Fn use, top dial
weapon, touch bar swipe strafe, INFO automap, Trash Doom menu, MENU quits.
One game per power-on.
