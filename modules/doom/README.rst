doom
====

Doom (doomgeneric engine) for the EOS R. No game data included: copy DOOM1.WAD
(shareware), your own DOOM.WAD / DOOM2.WAD or a FreeDoom WAD into ML/DOOM on the
card, then Games > Doom > SET. Music (optional): tools/eosr/doom-musrender.

Controls: joystick move/turn, SET or AF-ON fire, PLAY or M-Fn use, top dial
weapon, touch bar swipe strafe, INFO automap, Trash Doom menu, MENU quits.
One game per power-on.
