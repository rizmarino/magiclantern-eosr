# Support (EOS R fork)

This is an unofficial, experimental Magic Lantern build for the Canon EOS R (firmware 1.8.0), maintained in spare
time. Support is **best effort**; there is no guarantee of replies, fixes or releases.

- **Read first:** [docs/eos-r](docs/eos-r/README.md), especially [known limitations](docs/eos-r/known-limitations.md).
- **Questions** (how to, compatibility, ideas): [Discussions](https://github.com/rizmarino/magiclantern-eosr/discussions).
- **Bugs:** open an issue with the bug template and attach the card's logs (`CRASHnn.LOG`, `ML/LOGS/`,
  `ML/RECTEST.TXT`). Never attach `ML/LOGS/ROM*.BIN` (Canon firmware).
- **Don't report bugs of this fork to upstream Magic Lantern**: they didn't write this code.
- **Pull requests** are welcome but may not be reviewed quickly or at all. Upstream Magic Lantern's
  [LLM_POLICY](LLM_POLICY.md) applies to upstream contributions, not to this fork.

After a freeze: switch off (battery out if needed) and read the card on a PC before the next start.
Use this software at your own risk; keep a card without ML for work that matters.
